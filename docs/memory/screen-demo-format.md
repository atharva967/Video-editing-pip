Added 2026-10-09 for the Rekroots outreach walkthrough ("how to post a job"), matching the
user's reference https://www.instagram.com/reel/DdL_g4yT7R_/ (@divyam.explains showing a
Screen Studio-type editor): recording in a rounded browser window on a brand wallpaper,
virtual camera easing between zoom targets, dead time sped up.

`remotion/src/screendemo/ScreenDemo.tsx`, driven entirely by a props JSON (no builder):
`remotion/props/rekroots-demo.json` → `renders/rekroots-demo.mp4` (1920×1080, 35.8 s).
- `segs`: source ranges with `speed` (typing 3-4x) or `hold` (freeze frame)
- `camera`: `{at|o, rect:[x,y,w], dur}` in source px; `at` = source second mapped through
  the speed ramps, `o` = seconds into the demo; rect height follows the window aspect
- `clicks` (ripple + pop sfx, place ~0.3 s before the page changes), `spots` (outline +
  dim, optional label), numbered `captions`, logo `intro`/`outro`, music
- Render: `npx remotion render ScreenDemo ../renders/<id>.mp4 --props=props/<id>.json
  --jpeg-quality=100 --crf=16 --x264-preset=slow` with TEMP/TMP on E:

Workflow that worked: frame-diff the raw recording to find page changes/idle spans, read
field/button positions off contact sheets, then verify with `--sequence
--every-nth-frame=62` stills before the full render. Crop out the real browser bar and any
clipped sidebar / personal email via the base camera rect. Source was only 1260×684 and the user
called the first render blurry (2026-10-09). Fix: `pipeline/enhance_screen.py in.mp4 out-2x.mp4`
(forward+backward temporal denoise of static pixels, 2x Lanczos, unsharp + darker text;
~1.2 fps, ~25 min per 40 s) and point props `src` at the 2x file (keep srcW/srcH logical).
Always run it on low-res recordings before the edit; still ask for 1080p+ recordings.
**Per-lead personalisation (2026-10-09):** outreach demos get the lead's company + role on
screen. `patches` prop repaints UI text in source coords (bg box + text, optional scroll
`track`). For the Rekroots recording: dashboard heading = Space Grotesk 700 29.6px at
x218/baseline199.5 (source 1.33-3.63 s); applicant-page label = JetBrains Mono 500 10.3px,
ls 2.6, uppercase, #7B756F, with a scroll track 39.77-41.07 s. New lead = copy
`props/rekroots-demo-hinge-health.json`, change the two patch texts + intro tag/sub +
captions 2 and 8, render to `renders/rekroots-demo-<lead>.mp4`. Calibrate new patches by
first rendering the ORIGINAL words in red with no bg box. Keep temp/scratch on E: (C: hit
0 bytes again); use literal paths in rm (variable paths get blocked).
**Native replica is now the default for Rekroots outreach demos (2026-10-09):** the user
rejected the recording-based video twice for blur and needs the job description to change
per opening. `remotion/src/screendemo/RekrootsApp.tsx` redraws the employer flow as DOM
(landing, dashboard, chooser, post-a-role form with typed title/description/requirements/
skill chips, publish, postings + toast, applicant pipeline) in the same 1260x684 coordinate
space; ScreenDemo renders it when props has `app` (segs = one {a:0,b:31}; camera/clicks/
captions use `o` seconds; beat times in `TL`). New lead/job = copy
`props/rekroots-native-hinge-health.json`, edit `app.company` + `app.job` (title, type,
mode, description, requirements[], skills[], date) + intro/captions, render (~8 min, no
enhancement step). Don't go back to patching/upscaling the recording for this.
**Multi-role videos (2026-10-13):** leads often have 2 priority roles; user wants both in
ONE video. `app.jobs: Job[]` (each: title, type, mode, location, description,
requirements[], skills[], date): first role posted in full, later ones in a fast pass via
"+ New posting", final postings board spotlights all as live, pipeline shown for the last.
Timeline, camera, pointer, clicks, spots and captions are generated by `rekrootsScript()`
in RekrootsApp.tsx (props camera/captions are ignored in app mode). 2 roles = 49 s.
Example: `props/rekroots-instead-2roles.json` (lead = Instead, the AI tax platform; an earlier Hinge Health 2-role render was a misread of the user's message: if a lead brief has no clear company name, ASK before rendering). Add `--timeout=180000` to renders: headless browser setup timed out once at the 30 s default. When the user gives only role names,
draft short JD text grounded in the lead's real careers page and flag it as a draft.
**Length (2026-10-13):** user found the 49 s two-role video too long and asked for 30 s.
`app.fit` = target seconds for the product part; every beat scales to match (click/pointer
lead times stay absolute). 30 s total = intro.sec 1.5 + fit 26.3 + outro.sec 2.2, see
`props/rekroots-instead-2roles-30s.json`. Default new outreach videos to ~30 s.
